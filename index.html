GAP Playground

Write GAP code, run it on a fresh GitHub Actions machine, and read the result here.

How to use this playground

Type GAP code on the left and press Run (or Ctrl/⌘ + Enter). Your code runs on a fresh GitHub machine with the full GAP bundle, and the result appears on the right, usually within a minute. A run that has to wait for a machine can take a little longer.

Like the GAP prompt, a statement ending in ; shows its value (for example (1,2,3)^-1;), while ;; hides it. Print(…) works too. Load packages with LoadPackage("semigroups");. Runs stop after 120 seconds. Choose LaTeX above the output to typeset GAP results (permutations, matrices, fractions, powers, groups) automatically, plus any maths written between $…$ or $$…$$.

Connection settings

Use a fine-grained token limited to this one repository with Contents: read & write (sends the run request), Actions: read (downloads the result) and Checks: read (backup output channel). The token is kept only in this browser's local storage and is sent only to api.github.com.
